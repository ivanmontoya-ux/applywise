## Product

ApplyWise is an app and website for graduates in Europe who are applying for skilled roles. It helps users find better-fit jobs, tailor their applications, and keep every application organized from saved job to offer.

Core promise:

> Find and track better job applications with less chaos.

Positioning:

> ApplyWise is the organized way for graduates to find, prepare, and track job applications.

## Audience

- Graduates applying for skilled roles.
- Starting jobs and early-career roles remain the first practical product focus.
- Initial market: Europe.
- Initial language: English.
- Initial industries: business, tech, finance, consulting, and marketing.

## Brand Voice

The voice should be professional, supportive, calm, and direct. ApplyWise should feel like a practical career coach and organized productivity tool, not a loud motivational brand.

Use language like:

- "Here is your next best step."
- "Your CV could be stronger for this role."
- "You have 3 applications waiting for follow-up."
- "This job looks like a good fit based on your experience."

Avoid:

- Promising guaranteed job offers.
- Overclaiming what AI can do.
- Saying the app will apply on behalf of users unless that feature is explicitly added.
- Hype-heavy copy such as "beat the system" or "hack your career."

## MVP Scope

The first version should prioritize job finding and application tracking, then support the application workflow with document and reminder tools.

Core workflows:

1. Find graduate-relevant skilled jobs inside ApplyWise.
2. Save and track applications.
3. Get CV improvement suggestions for a selected job.
4. Generate customizable cover letters and reminders.

Application statuses:

- Saved
- Applied
- Interview
- Assessment
- Offer
- Rejected
- Withdrawn

Reminder types:

- Deadlines
- Follow-ups
- Interview prep
- Missing documents
- Weekly application goals

## Core Product Areas

### Home

Show today's tasks, upcoming reminders, recommended jobs, and weekly progress. The home view should help the user know what to do next.

### Jobs

Users should be able to search and discover jobs inside ApplyWise. Prioritize filters for role, industry, location, remote/hybrid, and experience level.

### Tracker

The tracker should provide a clear application pipeline using the approved statuses. It should make the user's job search feel organized and manageable.

### Documents

Users can store CVs, cover letters, templates, and job-specific versions. CV tailoring should suggest changes that the user approves.

### Coach

The assistant should combine admin help and career coaching. It can help users judge job fit, improve application materials, write cover letters, prepare for interviews, and decide next steps.

## Business Model

ApplyWise should support a freemium model.

Free tier ideas:

- Basic job search
- Basic application tracker
- Limited saved jobs
- Limited cover letters

Paid tier ideas:

- Unlimited applications
- Unlimited document versions
- Advanced CV suggestions
- Interview prep
- Smart reminders
- Job-search analytics

University plan ideas:

- Student access
- Branded onboarding
- Admin dashboard
- Anonymized usage insights only

## Privacy And Trust

ApplyWise stores CVs and personal data, so privacy must be treated as a core product feature.

Principles:

- Do not share private user information.
- Make privacy and data handling clear in user-facing copy.
- Ask for user approval before applying document suggestions.
- Avoid opaque automation around applications and personal documents.
- Design with GDPR expectations in mind for the European market.

## Design Direction

Visual style:

- Clean corporate
- Simple and approachable
- Calm, organized, and modern

The app should feel useful immediately. Avoid overly decorative marketing layouts when building product screens. Use clear navigation, practical empty states, and concise interface copy.

For iOS, a good starting tab structure is:

- Home
- Jobs
- Tracker
- Documents
- Coach

## Competitive Context

Europass already offers CV, cover letter, job, and career-planning tools in Europe. ApplyWise should not position itself as only another CV builder. Its stronger differentiation is the combined job-finding and application-tracking workflow, supported by document preparation, reminders, and coaching in one organized workspace for graduates.
